# Agitação - Shake Sort

## O que é?
Um algoritmo de ordenação parecido com o **Bubble Sort** (método da bolha), mas com desempenho melhor na prática.

## Como funciona?
* Percorre a lista da esquerda para a direita, empurrando o maior elemento para o final.
* Em seguida, percorre da direita para a esquerda, trazendo o menor elemento para o início.
* Repete esse movimento de "vai e vem" até que toda a lista esteja ordenada.

## Complexidade
* **Melhor caso:** `O(n)`
* **Caso médio e pior caso:** `O(n²)`

```java
void agitacao(List<int> lista) {
    bool houveTroca;
    int tmp;
    int ini = 0;
    int fim = lista.Count;
    int qtdComparacoes = 0, qtdTrocas = 0; //avalia a complexidade ou o esforço
    do {
        houveTroca = false;
        for (int i = ini; i < fim - 1; i++)
        {
            qtdComparacoes++;
            if(lista[i] > lista[i+1]){
                qtdTrocas++;
                houveTroca = true;
                tmp = lista[i];
                lista[i] = lista[i + 1];
                lista[i+1] = tmp;
            }
        }
        if (!houveTroca) {
            break;
        }
        fim--;
        
        houveTroca = false;
        // (continuação do laço de volta...)
    } while (houveTroca);
}
```
